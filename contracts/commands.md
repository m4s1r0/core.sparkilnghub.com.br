# Contrato de comandos do repositório

Comandos estáveis que documentação, CI e agentes usam (F00 a F03). Executam igual em Windows (PowerShell) e
Linux; implementados como scripts Node chamados por `npm run`. Nenhum comando aceita segredo por
argumento de linha de comando. Origem: F00 (`specs/001-f00-base-decisoes/contracts/commands.md`)
e F01 (`specs/002-f01-identidade-contextos/contracts/commands-f01.md`).

## Ambiente e verificação (F00)

| Comando                                    | Efeito                                                                                                                                                                                                                             | Ambientes permitidos                                               | Código de saída                                   |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------- |
| `npm run dev:up`                           | Sobe MySQL (compose), reaplica o init de usuários, migra Core, carrega sementes, inicia servidor, trabalhador e interface                                                                                                          | `development`                                                      | 0 ao ficar saudável; ≠0 com mensagem e componente |
| `npm run dev:down`                         | Para processos e contêiner, preservando volume                                                                                                                                                                                     | `development`                                                      | 0                                                 |
| `npm run dev:reset`                        | Recria bancos de desenvolvimento vazios (inclusive bancos de acesso `_acc` das instâncias sintéticas), migra e carrega sementes                                                                                                    | `development` apenas; recusa se `environment_marker` ≠ development | 0 / 2 recusado                                    |
| `npm run db:migrate`                       | Aplica migrações do Core (`spark_core`, `spark_identity`)                                                                                                                                                                          | todos                                                              | 0 / ≠0 com versão e motivo                        |
| `npm run db:seed`                          | Carrega dados sintéticos de forma idempotente (F02: contratante e produto de referência; instâncias A e B **pelo provisionador**, ativadas; credencial do `sparkref` com `sessions,members,connection`; contas ana, bruno e carla) | `development`, `homologation`                                      | 0 / 2 recusado                                    |
| `npm run ref:validate`                     | Valida o artefato do produto de referência (manifesto, checksums, construções proibidas)                                                                                                                                           | todos                                                              | 0 / ≠0                                            |
| `npm run artifact:validate -- <diretório>` | Valida qualquer artefato de produto (manifesto, checksums, construções proibidas); não acessa banco nem `.env`. Primeiro passo antes de registrar um produto em `PROVISIONERS` (contracts/migration-artifact.md)                   | todos                                                              | 0 / ≠0                                            |
| `npm run verify`                           | Executa localmente as etapas da CI                                                                                                                                                                                                 | `development`                                                      | 0 se todas passam                                 |
| `npm run gate -- <fatia>`                  | Verifica se a fatia pode estar `pronta` (decisões exigidas confirmadas)                                                                                                                                                            | todos                                                              | 0 / 3 bloqueada, listando decisões                |

## Identidade e projeção de acesso (F01)

| Comando                                                                         | Efeito                                                                                                                                                                         | Ambientes                                          | Código de saída                                                                                                           |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `npm run bootstrap:admin -- <email>`                                            | Gera o convite do primeiro administrador da plataforma (48 h) e imprime o link uma única vez; recusa se já houver administrador ativo ou convite de plataforma pendente válido | todos (produção pelo responsável pela implantação) | 0 com link; 3 recusado; 1 uso inválido                                                                                    |
| `npm run app-credential -- create <produto> <rótulo> --scopes sessions,members` | Cria credencial de aplicação e imprime `<id>.<segredo>` uma única vez                                                                                                          | todos                                              | 0 / 1                                                                                                                     |
| `npm run app-credential -- revoke <id>`                                         | Revoga credencial (efeito imediato)                                                                                                                                            | todos                                              | 0                                                                                                                         |
| `npm run app-credential -- list`                                                | Lista credenciais sem segredos                                                                                                                                                 | todos                                              | 0                                                                                                                         |
| `npm run access:reconcile -- <slug>`                                            | Recalcula a projeção de acesso da instância a partir de `spark_identity` e registra as divergências corrigidas (FR-033)                                                        | todos                                              | 0 sem divergência ou com correções (contagem impressa); 2 instância inexistente ou ambígua; 4 banco de acesso inacessível |

Recusas por ambiente gravam uma linha de log estruturado com `event: "env_guard_refused"`,
comando, `SPARK_ENV` e marcador encontrado. Links e segredos impressos uma única vez não ficam em
log nem no banco (só o sha256).

## Provisionamento (F02)

| Comando                                                                                    | Efeito                                                                                                                                                                                                             | Ambientes | Código de saída                                                       |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------- | --------------------------------------------------------------------- |
| `npm run instances:migrate-access`                                                         | Aplica a versão vigente da projeção de acesso em todas as instâncias com banco de acesso, com a credencial do provisionador; lista as inacessíveis. `dev:up`, `dev:reset` e a CI o executam depois de `db:migrate` | todos     | 0 todas atualizadas; 4 alguma inacessível (as demais são atualizadas) |
| `npm run app-credential -- create <produto> <rótulo> --scopes sessions,members,connection` | Aceita o escopo `connection` (contrato de conexão da instância)                                                                                                                                                    | todos     | 0 / 1                                                                 |

O trabalhador passa a exigir `MYSQL_PROVISIONER_PASSWORD` e `INSTANCE_SECRET_KEY` e executa as
tarefas de provisionamento; o servidor exige `INSTANCE_SECRET_KEY` (contrato de conexão).
Variáveis novas: `INSTANCE_SECRET_KEY`, `INSTANCE_SECRET_KEY_VERSION`, `INSTANCE_DB_HOST`,
`INSTANCE_DB_PORT`, `PROVISIONING_MAX_ATTEMPTS` (`.env.example`).

## Ciclo e operação da instância (F03)

Detalhes em `specs/004-f03-ciclo-operacao-instancia/contracts/commands-f03.md`; procedimento de
migração de instância em [`docs/operacao/migracao-instancia.md`](../docs/operacao/migracao-instancia.md).

| Comando                                                                                                               | Efeito                                                                                                                                                                                                                                 | Ambientes permitidos | Código de saída                                                   |
| --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ----------------------------------------------------------------- |
| `npm run instances:report-backup -- <instanceId> <ok\|falhou> [--origin <nome>] [--detail <texto>] [--takenAt <ISO>]` | Grava `instance_backup_record`. `<instanceId>` é o **UUID** da instância (não slug nem checksum). Conta como backup prévio da migração só com `taken_at` ≥ última entrada em `MANUTENCAO`; sem `--takenAt`, vale o instante do comando | todos                | 0 / 1 instância inexistente / 2 argumento inválido (nada gravado) |
| `npm run db:migrate`                                                                                                  | Também aplica `spark_core` 0009 (`admin_task.from_version`, adendo 2026-11-13); obrigatório antes de subir servidor/trabalhador com a aba "Migração" revista                                                                           | todos                | inalterado                                                        |

## Endurecimento de segurança (v1.4)

Detalhes em `specs/008-endurecimento-seguranca-core/contracts/internal-v1.4.md`; procedimento em
[`docs/operacao/credenciais-aplicacao.md`](../docs/operacao/credenciais-aplicacao.md).

| Comando                                                                                                            | Efeito                                                                                                                                               | Ambientes | Código de saída               |
| ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | ----------------------------- |
| `npm run app-credential -- create <produto> <rótulo> --scopes sessions,members,connection --instance <slug\|uuid>` | Credencial vinculada à instância (SEC-01). Escopos `connection`, `sessions` e `members` sem `--instance`, ou instância de outro produto → recusa     | todos     | 0 / 1                         |
| `npm run app-credential -- bind <id> --instance <slug\|uuid>`                                                      | Vincula credencial por produto existente à instância, sem trocar o segredo (migração sem parada); credencial já vinculada a outra instância → recusa | todos     | 0 / 1                         |
| `npm run app-credential -- list`                                                                                   | Mostra a instância de cada credencial e marca `POR PRODUTO — recusada` as que precisam de `bind`                                                     | todos     | 0                             |
| `npm run instances:sync-grants`                                                                                    | Reaplica os privilégios da credencial operacional de todas as instâncias: só-inserção (SEC-12), `REQUIRE SSL` e projeção (SEC-15)                    | todos     | 0 todas; 4 alguma inacessível |
| `npm run audit:deps`                                                                                               | `npm audit --omit=dev --audit-level=moderate` (SEC-09); etapa de `npm run verify` e da CI                                                            | —         | 0 limpo / 1 achado            |

Variáveis novas (`.env.example`): `TRUSTED_PROXIES`, `MYSQL_TLS`, `MYSQL_TLS_CA`,
`INSTANCE_DB_USER_HOST`. Fora de `development`, `MYSQL_TLS=off` e `INSTANCE_DB_USER_HOST=%` impedem
a inicialização.
